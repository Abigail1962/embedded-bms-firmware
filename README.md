# BMS control logic: host software-in-the-loop simulation

This executable runs on macOS/Linux with mocked peripheral structures. It has
not been cross-compiled, flashed, or validated on STM32F446RE hardware.
The mock structs are NOT hardware-compatible CMSIS register layouts.

~~~sh
make all test
python3 tests/sil_test_runner.py
~~~

The safety controller checks twelve cells, over/undervoltage, non-finite samples,
temperature faults, and a voltage fault latch. Tests execute C and check mock GPIO;
each runs in a fresh process to isolate latch state. The Python runner checks 30
simulation states. No test measures hardware response latency or qualifies as HIL.

UART uses an atomic single-producer/single-consumer RX ring and polling TX.
CAN is a print-only stub. PID output is demonstration-only and drives no actuator.
ADC and temperature readings are generated by independent host stimulus helpers.
The 5 V ADC scale is a simulation convention, not the board analog input limit.
Fault clearing in the demo is not a validated reset protocol.

Remaining target work: clocks, pin mux, CMSIS headers, startup/vector table,
linker script, ADC scan and trigger, NVIC, bus errors/timeouts, data freshness,
short ISR/deferred sensor acquisition and logging, and real peripheral validation.
No MISRA compliance, MC/DC coverage, or real-time guarantees have been established.

## STM32F446RE firmware target

[Standalone MCU target](firmware/stm32f446-bench/README.md) includes register-level
MPU6050 I2C, UART interrupt rings, circular ADC DMA, TIM2, safety fault handling
and bxCAN internal silent loopback. Both bare-metal and actual FreeRTOS V11.1.0
kernel variants compile and link with ARM GCC and warnings treated as errors.
This is separate from the host mock above. Board execution, peripheral timing
and electrical behavior remain unverified. Cell inputs are synthetic and the
output is an LED surrogate. See the target README for wiring and validation.

```sh
cd firmware/stm32f446-bench
python3 build.py
clang -Wall -Wextra -Werror -std=c11 -fsanitize=address,undefined -Iinclude src/controller.c src/mpu6050.c tests/test_logic.c -o build/test_logic
./build/test_logic
```
